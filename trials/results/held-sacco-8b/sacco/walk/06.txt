<excerpt file="README.md" kind="code">
1: # Sacco
2: 
3: The back office of a small savings and credit co-operative in Kenya. It keeps members
4: and their shares, takes deposits, lends against savings, collects repayments, charges
5: interest and tells members what is happening.
6: 
7: ## Layout
8: 
9: - `sacco/members`: the member register, shares and identity checks.
10: - `sacco/savings`: savings accounts, the ledger, deposits, withdrawals and dividends.
11: - `sacco/loans`: products, eligibility, applications, guarantors, schedules, fees and sending money out.
12: - `sacco/interest`: monthly interest, accrual and late penalties.
13: - `sacco/repayments`: splitting a payment, applying it, arrears and recovery.
14: - `sacco/statements`: statements for savings and for loans.
15: - `sacco/notify`: message templates, delivery channels and who gets told what.
16: - `sacco/api`: request validation and the handlers the web layer calls.
17: - `sacco/reports`: portfolio and monthly figures for the board.
18: - `sacco/store`: an in-memory store with small repository helpers.
19: 
20: Money is held as whole cents. Times are whole seconds since the epoch, taken from
21: `sacco.clock` so tests can control them. Rates are basis points per month.
22: 
23: ## Running the tests
24:

"""Sending an approved loan to the member."""

from ..errors import InvalidLoanState
from ..models import LOAN_ACTIVE, LOAN_APPROVED, Disbursement, Loan
from ..money import basis_points_of
from ..store.repositories import get_loan, get_member, save_loan
from .fees import record_fee_income

PROCESSING_FEE_BASIS_POINTS = 150


def processing_fee(amount_cents: int) -> int:
    return basis_points_of(amount_cents, PROCESSING_FEE_BASIS_POINTS)


def _activate(store, loan: Loan, clock) -> Loan:
    loan.status = LOAN_ACTIVE
    loan.disbursed_at = clock.now()
    loan.outstanding_principal_cents = loan.principal_cents
    return save_loan(store, loan)


def disburse_loan(store, loan_id: str, gateway, clock) -> Disbursement:
    loan = get_loan(store, loan_id)
    if loan.status != LOAN_APPROVED:
        raise InvalidLoanState(loan_id, loan.status)
    member = get_member(store, loan.member_id)
    fee = processing_fee(loan.principal_cents)
    sent = loan.principal_cents - fee
    transfer = gateway.send(member.phone, sent, reference=loan.id)
    _activate(store, loan, clock)
    record_fee_income(store, loan.id, fee, clock)
    return Disbursement(loan.id, sent_cents=sent, fee_cents=fee, receipt_id=transfer.transfer_id)
