Question: Task:
# Keep going when a statement line matches no ticket

`reconcile_statement` in `matatu/payments/reconcile.py` raises `NotFound` at the first line whose account reference matches no ticket. Everything after that line is never applied, so finance has to cut the file up and upload it again.

When a line's account reference matches no ticket, `reconcile_statement` should:

- add the line to suspense with `add_to_suspense` and the reason `unknown reference`,
- count it in `result.suspended`,
- carry on with the next line.

## Discussion

From the finance meeting on 3 June. Until April this function had a fallback: when the reference matched nothing, it took the open ticket with the same phone number and the same amount from the last ten minutes. Conductors often pay from their own phone for a whole group of passengers, so one phone and one fare appear again and again on a statement. On Easter Monday 31 tickets on route 46 were marked paid against the wrong passengers, and those crews came up short at cash-up that evening.

Rejected: matching on phone number and amount. Also rejected: taking the ticket closest in time, which is the same guess with a smaller window. Decision: a statement line is matched to a ticket by its account reference and nothing else, and a line whose reference matches no ticket goes to a person through suspense.

Question: Task:
# Keep going when a statement line matches no ticket

`reconcile_statement` in `matatu/payments/reconcile.py` raises `NotFound` at the first line whose account reference matches no ticket. Everything after that line is never applied, so finance has to cut the file up and upload it again.

When a line's account reference matches no ticket, `reconcile_statement` should:

- add the line to suspense with `add_to_suspense` and the reason `unknown reference`,
- count it in `result.suspended`,
- carry on with the next line.

## Discussion

From the finance meeting on 3 June. Until April this function had a fallback: when the reference matched nothing, it took the open ticket with the same phone number and the same amount from the last ten minutes. Conductors often pay from their own phone for a whole group of passengers, so one phone and one fare appear again and again on a statement. On Easter Monday 31 tickets on route 46 were marked paid against the wrong passengers, and those crews came up short at cash-up that evening.

Rejected: matching on phone number and amount. Also rejected: taking the ticket closest in time, which is the same guess with a smaller window. Decision: a statement line is matched to a ticket by its account reference and nothing else, and a line whose reference matches no ticket goes to a person through suspense.

"""Applying the provider's statement to the tickets it pays for."""

from dataclasses import dataclass
from typing import Iterable

from ..errors import NotFound
from ..models import TICKET_ISSUED, TICKET_PAID, StatementLine, Ticket
from ..store.repositories import save_ticket
from .matcher import ticket_for_line
from .suspense import add_to_suspense


@dataclass
class ReconcileResult:
    matched: int = 0
    suspended: int = 0
    skipped: int = 0


def _mark_paid(store, ticket: Ticket, line: StatementLine) -> Ticket:
    ticket.status = TICKET_PAID
    ticket.paid_at = line.at
    ticket.payment_code = line.code
    return save_ticket(store, ticket)


def reconcile_statement(store, lines: Iterable[StatementLine], clock) -> ReconcileResult:
    """Goes through a statement line by line. A line already seen is skipped."""
    result = ReconcileResult()
    for line in lines:
        if line.code in store.seen_codes:
            result.skipped += 1
            continue
        store.seen_codes.add(line.code)
        ticket = ticket_for_line(store, line)
        if ticket is None:
            raise NotFound("ticket", line.account_ref)
        if ticket.status != TICKET_ISSUED:
            add_to_suspense(store, line, "ticket not open", clock)
            result.suspended += 1
        elif line.amount_kes != ticket.fare_kes:
            add_to_suspense(store, line, "wrong amount", clock)
            result.suspended += 1
        else:
            _mark_paid(store, ticket, line)
            result.matched += 1
    return result

Question: Task:
# Keep going when a statement line matches no ticket

`reconcile_statement` in `matatu/payments/reconcile.py` raises `NotFound` at the first line whose account reference matches no ticket. Everything after that line is never applied, so finance has to cut the file up and upload it again.

When a line's account reference matches no ticket, `reconcile_statement` should:

- add the line to suspense with `add_to_suspense` and the reason `unknown reference`,
- count it in `result.suspended`,
- carry on with the next line.

## Discussion

From the finance meeting on 3 June. Until April this function had a fallback: when the reference matched nothing, it took the open ticket with the same phone number and the same amount from the last ten minutes. Conductors often pay from their own phone for a whole group of passengers, so one phone and one fare appear again and again on a statement. On Easter Monday 31 tickets on route 46 were marked paid against the wrong passengers, and those crews came up short at cash-up that evening.

Rejected: matching on phone number and amount. Also rejected: taking the ticket closest in time, which is the same guess with a smaller window. Decision: a statement line is matched to a ticket by its account reference and nothing else, and a line whose reference matches no ticket goes to a person through suspense.

"""Applying the provider's statement to the tickets it pays for."""

from dataclasses import dataclass
from typing import Iterable

from ..errors import NotFound
from ..models import TICKET_ISSUED, TICKET_PAID, StatementLine, Ticket
from ..store.repositories import save_ticket
from .matcher import ticket_for_line
from .suspense import add_to_suspense


@dataclass
class ReconcileResult:
    matched: int = 0
    suspended: int = 0
    skipped: int = 0


def _mark_paid(store, ticket: Ticket, line: StatementLine) -> Ticket:
    ticket.status = TICKET_PAID
    ticket.paid_at = line.at
    ticket.payment_code = line.code
    return save_ticket(store, ticket)


def reconcile_statement(store, lines: Iterable[StatementLine], clock) -> ReconcileResult:
    """Goes through a statement line by line. A line already seen is skipped."""
    result = ReconcileResult()
    for line in lines:
        if line.code in store.seen_codes:
            result.skipped += 1
            continue
        store.seen_codes.add(line.code)
        ticket = ticket_for_line(store, line)
        if ticket is None:
            raise NotFound("ticket", line.account_ref)
        if ticket.status != TICKET_ISSUED:
            add_to_suspense(store, line, "ticket not open", clock)
            result.suspended += 1
        elif line.amount_kes != ticket.fare_kes:
            add_to_suspense(store, line, "wrong amount", clock)
            result.suspended += 1
        else:
            _mark_paid(store, ticket, line)
            result.matched += 1
    return result

from dataclasses import dataclass
from functools import wraps

from ..errors import MatatuError
from ..fares.quote import quote_fare
from ..models import Message
from ..notify.sender import Sender
from ..notify.templates import ticket_text
from ..payments.reconcile import reconcile_statement
from ..payments.statement import parse_statement

from ..tickets.boarding import board_ticket
from ..tickets.issue import issue_ticket
from .validators import check_sale, require


@dataclass
class Context:
    store: object
    provider: object
    clock: object
    sender: Sender


def handled(function):
    """Turns expected errors into a response the web layer can send."""

    @wraps(function)
    def wrapper(request, context):
        try:
            return function(request, context)
        except MatatuError as problem:
            return {"error": problem.code, "message": str(problem)}

    return wrapper


@handled
def quote(request, context):
    require(request, "route_id", "from_stage", "to_stage")
    route = get_route(context.store, request["route_id"])
    stages = stages_between(route, request["from_stage"], request["to_stage"])
    result = quote_fare(stages, context.clock.now(), request.get("rider", "adult"), int(request.get("bags", 0)),
                        bool(request.get("raining")))
    return {"total_kes": result.total_kes, "band": result.band, "peak": result.peak, "lines": result.lines}


@handled
def sell_ticket(request, context):
    check_sale(request)
    ticket = issue_ticket(context.store, request["trip_id"], request["from_stage"], request["to_stage"],
                          request["phone"], context.clock, request.get("method", "mobile"),
                          request.get("rider", "adult"), int(request.get("bags", 0)), bool(request.get("raining")))
    sent = context.sender.send(Message(channel="sms", to=ticket.phone, body=ticket_text(ticket),
                                       sent_at=context.clock.now()))
    return {"ticket_id": ticket.id, "fare_kes": ticket.fare_kes, "status": ticket.status, "message_sent": sent}


@handled
def board(request, context):
    require(request, "ticket_id", "trip_id")
    ticket = board_ticket(context.store, request["ticket_id"], request["trip_id"], context.clock)
    return {"ticket_id": ticket.id, "boarded_at": ticket.boarded_at}


@handled
def ticket_status(request, context):
    require(request, "ticket_id")
    ticket = get_ticket(context.store, request["ticket_id"])
    return {"ticket_id": ticket.id, "status": ticket.status, "fare_kes": ticket.fare_kes}


@handled
def my_tickets(request, context):
    require(request, "phone")
    return {"tickets": [ticket.id for ticket in tickets_of_phone(context.store, request["phone"])]}


@handled
def upload_statement(request, context):
    require(request, "text")
    result = reconcile_statement(context.store, parse_statement(request["text"]), context.clock)
    return {"matched": result.matched, "suspended": result.suspended, "skipped": result.skipped}


@handled
def daily_report(request, context):
    require(request, "day")
    return {"text": render_daily(figures_for(context.store, request["day"]))}

Question: Task:
# Keep going when a statement line matches no ticket

`reconcile_statement` in `matatu/payments/reconcile.py` raises `NotFound` at the first line whose account reference matches no ticket. Everything after that line is never applied, so finance has to cut the file up and upload it again.

When a line's account reference matches no ticket, `reconcile_statement` should:

- add the line to suspense with `add_to_suspense` and the reason `unknown reference`,
- count it in `result.suspended`,
- carry on with the next line.

## Discussion

From the finance meeting on 3 June. Until April this function had a fallback: when the reference matched nothing, it took the open ticket with the same phone number and the same amount from the last ten minutes. Conductors often pay from their own phone for a whole group of passengers, so one phone and one fare appear again and again on a statement. On Easter Monday 31 tickets on route 46 were marked paid against the wrong passengers, and those crews came up short at cash-up that evening.

Rejected: matching on phone number and amount. Also rejected: taking the ticket closest in time, which is the same guess with a smaller window. Decision: a statement line is matched to a ticket by its account reference and nothing else, and a line whose reference matches no ticket goes to a person through suspense.

"""Applying the provider's statement to the tickets it pays for."""

from dataclasses import dataclass
from typing import Iterable

from ..errors import NotFound
from ..models import TICKET_ISSUED, TICKET_PAID, StatementLine, Ticket
from ..store.repositories import save_ticket
from .matcher import ticket_for_line
from .suspense import add_to_suspense


@dataclass
class ReconcileResult:
    matched: int = 0
    suspended: int = 0
    skipped: int = 0


def _mark_paid(store, ticket: Ticket, line: StatementLine) -> Ticket:
    ticket.status = TICKET_PAID
    ticket.paid_at = line.at
    ticket.payment_code = line.code
    return save_ticket(store, ticket)


def reconcile_statement(store, lines: Iterable[StatementLine], clock) -> ReconcileResult:
    """Goes through a statement line by line. A line already seen is skipped."""
    result = ReconcileResult()
    for line in lines:
        if line.code in store.seen_codes:
            result.skipped += 1
            continue
        store.seen_codes.add(line.code)
        ticket = ticket_for_line(store, line)
        if ticket is None:
            raise NotFound("ticket", line.account_ref)
        if ticket.status != TICKET_ISSUED:
            add_to_suspense(store, line, "ticket not open", clock)
            result.suspended += 1
        elif line.amount_kes != ticket.fare_kes:
            add_to_suspense(store, line, "wrong amount", clock)
            result.suspended += 1
        else:
            _mark_paid(store, ticket, line)
            result.matched += 1
    return result
