Question: Task:
# Day-close report for the treasurer

Add `matatu/reports/day_close.py` with `day_close(store, day)`, where `day` is a string like `2023-11-15`. It returns a dictionary with these keys:

- `day`: the day asked for,
- `tickets`: how many tickets with the status `paid` belong to that day,
- `takings_kes`: the total of their fares,
- `by_route`: a dictionary of route id to that route's takings.

Tickets are placed by their `issued_at`. A day with nothing on it returns zeros and an empty `by_route`.

Add a handler `day_close_report(request, context)` to `matatu/api/handlers.py`. It takes `{"day": ...}` and returns the dictionary from `day_close`, using the `handled` decorator like the other handlers. A request with no `day` gets the usual `invalid` error.

## Discussion

Talked this through with the treasurer and the Eastlands depot on 18 September. Our first draft counted calendar days. The night service on routes 58 and 19C runs until about 02:30, and those crews hand in one envelope at 03:00 for the whole night. Cutting at midnight split one night's takings over two reports, so over the Madaraka weekend Saturday looked short, Sunday looked long, and the treasurer sent both back.

Decision: a day in this business is an operating day, running from 03:00 to 03:00 Nairobi time, so a ticket issued at 01:30 on the 16th belongs to the 15th. Everything built from now on that asks which day something happened on uses the operating day. Only the existing `figures_for` stays on calendar days, since finance compares it line by line with the provider's statement, which runs midnight to midnight.

Rejected: calendar days, and rejected a different cut-over hour per route, since a crew can change routes during a night.

Question: Task:
# Day-close report for the treasurer

Add `matatu/reports/day_close.py` with `day_close(store, day)`, where `day` is a string like `2023-11-15`. It returns a dictionary with these keys:

- `day`: the day asked for,
- `tickets`: how many tickets with the status `paid` belong to that day,
- `takings_kes`: the total of their fares,
- `by_route`: a dictionary of route id to that route's takings.

Tickets are placed by their `issued_at`. A day with nothing on it returns zeros and an empty `by_route`.

Add a handler `day_close_report(request, context)` to `matatu/api/handlers.py`. It takes `{"day": ...}` and returns the dictionary from `day_close`, using the `handled` decorator like the other handlers. A request with no `day` gets the usual `invalid` error.

## Discussion

Talked this through with the treasurer and the Eastlands depot on 18 September. Our first draft counted calendar days. The night service on routes 58 and 19C runs until about 02:30, and those crews hand in one envelope at 03:00 for the whole night. Cutting at midnight split one night's takings over two reports, so over the Madaraka weekend Saturday looked short, Sunday looked long, and the treasurer sent both back.

Decision: a day in this business is an operating day, running from 03:00 to 03:00 Nairobi time, so a ticket issued at 01:30 on the 16th belongs to the 15th. Everything built from now on that asks which day something happened on uses the operating day. Only the existing `figures_for` stays on calendar days, since finance compares it line by line with the provider's statement, which runs midnight to midnight.

Rejected: calendar days, and rejected a different cut-over hour per route, since a crew can change routes during a night.

from dataclasses import dataclass
from functools import wraps

from ..errors import MatatuError
from ..fares.quote import quote_fare
from ..models import Message
from ..notify.sender import Sender
from ..notify.templates import ticket_text
from ..payments.reconcile import reconcile_statement
from ..payments.statement import parse_statement

@dataclass
class Context:
    store: object
    provider: object
    clock: object
    sender: Sender


def handled(function):
    """Turns expected errors into a response the web layer can send."""

    @wraps(function)
    def wrapper(request, context):
        try:
            return function(request, context)
        except MatatuError as problem:
            return {"error": problem.code, "message": str(problem)}

    return wrapper

"""The figures sent to finance each morning."""

from collections import Counter
from dataclasses import dataclass
from typing import Dict

from ..clock import day_of
from ..models import METHOD_CASH, METHOD_MOBILE, TICKET_PAID, TICKET_REFUNDED
from ..money import format_kes


@dataclass
class DailyFigures:
    day: str
    tickets_paid: int
    cash_kes: int
    mobile_kes: int
    refunded_kes: int
    methods: Dict[str, int]

    def net_kes(self) -> int:
        return self.cash_kes + self.mobile_kes - self.refunded_kes


def figures_for(store, day: str) -> DailyFigures:
    paid = [t for t in store.tickets.values()
            if t.status in (TICKET_PAID, TICKET_REFUNDED) and t.paid_at is not None and day_of(t.paid_at) == day]
    counted = Counter(t.method for t in paid)
    return DailyFigures(day=day, tickets_paid=len(paid),
                        cash_kes=sum(t.fare_kes for t in paid if t.method == METHOD_CASH),
                        mobile_kes=sum(t.fare_kes for t in paid if t.method == METHOD_MOBILE),
                        refunded_kes=sum(t.fare_kes for t in paid if t.status == TICKET_REFUNDED),
                        methods=dict(counted))


def render_daily(figures: DailyFigures) -> str:
    return "\n".join([
        f"Daily figures for {figures.day}",
        f"Tickets paid: {figures.tickets_paid}",
        f"Cash: {format_kes(figures.cash_kes)}",
        f"Mobile money: {format_kes(figures.mobile_kes)}",
        f"Refunded: {format_kes(figures.refunded_kes)}",
        f"Net: {format_kes(figures.net_kes())}",
    ])

from ..config import COMMISSION_EXCLUDED_ROUTES, CONDUCTOR_COMMISSION_PERCENT, DRIVER_COMMISSION_PERCENT, ROLE_DRIVER

def rate_for(member: CrewMember) -> int:
    return DRIVER_COMMISSION_PERCENT if member.role == ROLE_DRIVER else CONDUCTOR_COMMISSION_PERCENT


def commission_on(ticket: Ticket, member: CrewMember) -> int:
    if ticket.route_id in COMMISSION_EXCLUDED_ROUTES:
        return 0
    return percent_of(ticket.fare_kes, rate_for(member))


def _in_shift(ticket: Ticket, shift: Shift) -> bool:
    if ticket.vehicle_id != shift.vehicle_id or ticket.status != TICKET_PAID:
        return False
    return ticket.issued_at >= shift.started_at and (shift.ended_at is None or ticket.issued_at <= shift.ended_at)


def commission_for_shift(store, shift: Shift) -> int:
    member = get_crew_member(store, shift.crew_id)
    return sum(commission_on(ticket, member) for ticket in store.tickets.values() if _in_shift(ticket, shift))

"""Where the back office gets the time, so tests can control it."""

import calendar
import time
from datetime import datetime, timezone

from .config import LOCAL_OFFSET_HOURS, SECONDS_PER_HOUR


class SystemClock:
    def now(self) -> int:
        return int(time.time())


class FixedClock:
    """A clock that only moves when told to."""

    def __init__(self, start: int = 1_700_000_000):
        self.current = start

    def now(self) -> int:
        return self.current

    def advance(self, seconds: int) -> int:
        self.current += seconds
        return self.current


def hour_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The hour of the day at a moment, in local time."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).hour


def weekday_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """Monday is 0."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).weekday()


def day_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> str:
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).strftime("%Y-%m-%d")


def moment_of(day: str, hour: int, minute: int = 0, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The moment of a local time on a day written YYYY-MM-DD."""
    parsed = datetime.strptime(day, "%Y-%m-%d")
    return calendar.timegm(parsed.timetuple()) + (hour - offset_hours) * SECONDS_PER_HOUR + minute * 60

Question: Task:
# Day-close report for the treasurer

Add `matatu/reports/day_close.py` with `day_close(store, day)`, where `day` is a string like `2023-11-15`. It returns a dictionary with these keys:

- `day`: the day asked for,
- `tickets`: how many tickets with the status `paid` belong to that day,
- `takings_kes`: the total of their fares,
- `by_route`: a dictionary of route id to that route's takings.

Tickets are placed by their `issued_at`. A day with nothing on it returns zeros and an empty `by_route`.

Add a handler `day_close_report(request, context)` to `matatu/api/handlers.py`. It takes `{"day": ...}` and returns the dictionary from `day_close`, using the `handled` decorator like the other handlers. A request with no `day` gets the usual `invalid` error.

## Discussion

Talked this through with the treasurer and the Eastlands depot on 18 September. Our first draft counted calendar days. The night service on routes 58 and 19C runs until about 02:30, and those crews hand in one envelope at 03:00 for the whole night. Cutting at midnight split one night's takings over two reports, so over the Madaraka weekend Saturday looked short, Sunday looked long, and the treasurer sent both back.

Decision: a day in this business is an operating day, running from 03:00 to 03:00 Nairobi time, so a ticket issued at 01:30 on the 16th belongs to the 15th. Everything built from now on that asks which day something happened on uses the operating day. Only the existing `figures_for` stays on calendar days, since finance compares it line by line with the provider's statement, which runs midnight to midnight.

Rejected: calendar days, and rejected a different cut-over hour per route, since a crew can change routes during a night.

@dataclass
class Context:
    store: object
    provider: object
    clock: object
    sender: Sender


def handled(function):
    """Turns expected errors into a response the web layer can send."""

    @wraps(function)
    def wrapper(request, context):
        try:
            return function(request, context)
        except MatatuError as problem:
            return {"error": problem.code, "message": str(problem)}

    return wrapper


@handled
def quote(request, context):
    require(request, "route_id", "from_stage", "to_stage")
    route = get_route(context.store, request["route_id"])
    stages = stages_between(route, request["from_stage"], request["to_stage"])
    result = quote_fare(stages, context.clock.now(), request.get("rider", "adult"), int(request.get("bags", 0)),
                        bool(request.get("raining")))
    return {"total_kes": result.total_kes, "band": result.band, "peak": result.peak, "lines": result.lines}


@handled
def sell_ticket(request, context):
    check_sale(request)
    ticket = issue_ticket(context.store, request["trip_id"], request["from_stage"], request["to_stage"],
                          request["phone"], context.clock, request.get("method", "mobile"),
                          request.get("rider", "adult"), int(request.get("bags", 0)), bool(request.get("raining")))
    sent = context.sender.send(Message(channel="sms", to=ticket.phone, body=ticket_text(ticket),
                                       sent_at=context.clock.now()))
    return {"ticket_id": ticket.id, "fare_kes": ticket.fare_kes, "status": ticket.status, "message_sent": sent}

"""The figures sent to finance each morning."""

from collections import Counter
from dataclasses import dataclass
from typing import Dict

from ..clock import day_of
from ..models import METHOD_CASH, METHOD_MOBILE, TICKET_PAID, TICKET_REFUNDED
from ..money import format_kes


@dataclass
class DailyFigures:
    day: str
    tickets_paid: int
    cash_kes: int
    mobile_kes: int
    refunded_kes: int
    methods: Dict[str, int]

    def net_kes(self) -> int:
        return self.cash_kes + self.mobile_kes - self.refunded_kes


def figures_for(store, day: str) -> DailyFigures:
    paid = [t for t in store.tickets.values()
            if t.status in (TICKET_PAID, TICKET_REFUNDED) and t.paid_at is not None and day_of(t.paid_at) == day]
    counted = Counter(t.method for t in paid)
    return DailyFigures(day=day, tickets_paid=len(paid),
                        cash_kes=sum(t.fare_kes for t in paid if t.method == METHOD_CASH),
                        mobile_kes=sum(t.fare_kes for t in paid if t.method == METHOD_MOBILE),
                        refunded_kes=sum(t.fare_kes for t in paid if t.status == TICKET_REFUNDED),
                        methods=dict(counted))


def render_daily(figures: DailyFigures) -> str:
    return "\n".join([
        f"Daily figures for {figures.day}",
        f"Tickets paid: {figures.tickets_paid}",
        f"Cash: {format_kes(figures.cash_kes)}",
        f"Mobile money: {format_kes(figures.mobile_kes)}",
        f"Refunded: {format_kes(figures.refunded_kes)}",
        f"Net: {format_kes(figures.net_kes())}",
    ])

def fares_by_route(store, day: str) -> Dict[str, int]:

"""Where the back office gets the time, so tests can control it."""

import calendar
import time
from datetime import datetime, timezone

from .config import LOCAL_OFFSET_HOURS, SECONDS_PER_HOUR


class SystemClock:
    def now(self) -> int:
        return int(time.time())


class FixedClock:
    """A clock that only moves when told to."""

    def __init__(self, start: int = 1_700_000_000):
        self.current = start

    def now(self) -> int:
        return self.current

    def advance(self, seconds: int) -> int:
        self.current += seconds
        return self.current


def hour_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The hour of the day at a moment, in local time."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).hour


def weekday_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """Monday is 0."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).weekday()


def day_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> str:
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).strftime("%Y-%m-%d")


def moment_of(day: str, hour: int, minute: int = 0, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The moment of a local time on a day written YYYY-MM-DD."""
    parsed = datetime.strptime(day, "%Y-%m-%d")
    return calendar.timegm(parsed.timetuple()) + (hour - offset_hours) * SECONDS_PER_HOUR + minute * 60

Question: Task:
# Day-close report for the treasurer

Add `matatu/reports/day_close.py` with `day_close(store, day)`, where `day` is a string like `2023-11-15`. It returns a dictionary with these keys:

- `day`: the day asked for,
- `tickets`: how many tickets with the status `paid` belong to that day,
- `takings_kes`: the total of their fares,
- `by_route`: a dictionary of route id to that route's takings.

Tickets are placed by their `issued_at`. A day with nothing on it returns zeros and an empty `by_route`.

Add a handler `day_close_report(request, context)` to `matatu/api/handlers.py`. It takes `{"day": ...}` and returns the dictionary from `day_close`, using the `handled` decorator like the other handlers. A request with no `day` gets the usual `invalid` error.

## Discussion

Talked this through with the treasurer and the Eastlands depot on 18 September. Our first draft counted calendar days. The night service on routes 58 and 19C runs until about 02:30, and those crews hand in one envelope at 03:00 for the whole night. Cutting at midnight split one night's takings over two reports, so over the Madaraka weekend Saturday looked short, Sunday looked long, and the treasurer sent both back.

Decision: a day in this business is an operating day, running from 03:00 to 03:00 Nairobi time, so a ticket issued at 01:30 on the 16th belongs to the 15th. Everything built from now on that asks which day something happened on uses the operating day. Only the existing `figures_for` stays on calendar days, since finance compares it line by line with the provider's statement, which runs midnight to midnight.

Rejected: calendar days, and rejected a different cut-over hour per route, since a crew can change routes during a night.

"""The figures sent to finance each morning."""

from collections import Counter
from dataclasses import dataclass
from typing import Dict

from ..clock import day_of
from ..models import METHOD_CASH, METHOD_MOBILE, TICKET_PAID, TICKET_REFUNDED
from ..money import format_kes


@dataclass
class DailyFigures:
    day: str
    tickets_paid: int
    cash_kes: int
    mobile_kes: int
    refunded_kes: int
    methods: Dict[str, int]

    def net_kes(self) -> int:
        return self.cash_kes + self.mobile_kes - self.refunded_kes


def figures_for(store, day: str) -> DailyFigures:
    paid = [t for t in store.tickets.values()
            if t.status in (TICKET_PAID, TICKET_REFUNDED) and t.paid_at is not None and day_of(t.paid_at) == day]
    counted = Counter(t.method for t in paid)
    return DailyFigures(day=day, tickets_paid=len(paid),
                        cash_kes=sum(t.fare_kes for t in paid if t.method == METHOD_CASH),
                        mobile_kes=sum(t.fare_kes for t in paid if t.method == METHOD_MOBILE),
                        refunded_kes=sum(t.fare_kes for t in paid if t.status == TICKET_REFUNDED),
                        methods=dict(counted))


def render_daily(figures: DailyFigures) -> str:
    return "\n".join([
        f"Daily figures for {figures.day}",
        f"Tickets paid: {figures.tickets_paid}",
        f"Cash: {format_kes(figures.cash_kes)}",
        f"Mobile money: {format_kes(figures.mobile_kes)}",
        f"Refunded: {format_kes(figures.refunded_kes)}",
        f"Net: {format_kes(figures.net_kes())}",
    ])

from .config import LOCAL_OFFSET_HOURS, SECONDS_PER_HOUR


class SystemClock:
    def now(self) -> int:

class FixedClock:
    """A clock that only moves when told to."""

    def __init__(self, start: int = 1_700_000_000):
        self.current = start

    def now(self) -> int:
        return self.current

    def advance(self, seconds: int) -> int:
        self.current += seconds
        return self.current


def hour_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The hour of the day at a moment, in local time."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).hour


def weekday_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """Monday is 0."""
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).weekday()


def day_of(moment: int, offset_hours: int = LOCAL_OFFSET_HOURS) -> str:
    return datetime.fromtimestamp(moment + offset_hours * SECONDS_PER_HOUR, tz=timezone.utc).strftime("%Y-%m-%d")


def moment_of(day: str, hour: int, minute: int = 0, offset_hours: int = LOCAL_OFFSET_HOURS) -> int:
    """The moment of a local time on a day written YYYY-MM-DD."""
    parsed = datetime.strptime(day, "%Y-%m-%d")
    return calendar.timegm(parsed.timetuple()) + (hour - offset_hours) * SECONDS_PER_HOUR + minute * 60

"""
Day close report for the treasurer

Returns a dictionary with the following keys:

- `day`: the day asked for,
- `tickets`: how many tickets with the status `paid` belong to that day,
- `takings_kes`: the total of their fares,
- `by_route`: a dictionary of route id to that route's takings.

Tickets are placed by their `issued_at`. A day with nothing on it returns zeros and an empty `by_route`.

"""

from collections import defaultdict
from datetime import datetime
from typing import Dict, List, Tuple

from ..clock import day_of
from ..models import TICKET_PAID
from ..store.repositories import get_route, get_ticket, tickets_of_phone


def day_close(store, day: str) -> Dict[str, int]:
    # Calculate the operating day (03:00 to 03:00 Nairobi time)
    # Convert day string to moment (seconds since epoch)
    moment = moment_of(day, 3, 0, LOCAL_OFFSET_HOURS)
    
    # Get all tickets issued on the operating day
    tickets = [t for t in store.tickets.values() if day_of(t.issued_at) == day and t.status == TICKET_PAID]
    
    # Count tickets
    tickets_count = len(tickets)
    
    # Sum fares
    takings_kes = sum(t.fare_kes for t in tickets)
    
    # Group by route
    by_route = defaultdict(int)
    for t in tickets:
        by_route[t.route_id] += t.fare_kes
    
    return {
        "day": day,
        "tickets": tickets_count,
        "takings_kes": takings_kes,
        "by_route": by_route
    }
