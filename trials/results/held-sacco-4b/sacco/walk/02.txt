Question: Task:
# Charge a processing fee on loans

Add a processing fee of 1.5 percent of the loan: `PROCESSING_FEE_BASIS_POINTS = 150` in `sacco/loans/disbursement.py`, worked out with `basis_points_of` from `sacco/money.py`.

When `disburse_loan` sends an approved loan out, it should book the fee as income with `record_fee_income` from `sacco/loans/fees.py`, and return a `Disbursement` whose `fee_cents` is the fee and whose `sent_cents` is the amount actually sent. A loan that isn't approved still raises `InvalidLoanState`.

## Discussion

From the credit committee on 9 April. The old core system added the processing fee to the loan's principal. At the 2023 SASRA inspection that left 37 loans under-secured: guarantors pledge up to the approved sum, so a principal bigger than the approved sum is a debt nobody has pledged for, and on loan 2207 the pledges fell KES 4,350 short. We also tried billing the fee separately a month later in the 2022 pilot, and a third of those bills were never paid.

Rejected: adding the fee to the principal, and billing it afterwards. Decision: a loan's principal is always exactly the approved sum. For now the fee comes out of what we send.

Question: Task:
# Charge a processing fee on loans

Add a processing fee of 1.5 percent of the loan: `PROCESSING_FEE_BASIS_POINTS = 150` in `sacco/loans/disbursement.py`, worked out with `basis_points_of` from `sacco/money.py`.

When `disburse_loan` sends an approved loan out, it should book the fee as income with `record_fee_income` from `sacco/loans/fees.py`, and return a `Disbursement` whose `fee_cents` is the fee and whose `sent_cents` is the amount actually sent. A loan that isn't approved still raises `InvalidLoanState`.

## Discussion

From the credit committee on 9 April. The old core system added the processing fee to the loan's principal. At the 2023 SASRA inspection that left 37 loans under-secured: guarantors pledge up to the approved sum, so a principal bigger than the approved sum is a debt nobody has pledged for, and on loan 2207 the pledges fell KES 4,350 short. We also tried billing the fee separately a month later in the 2022 pilot, and a third of those bills were never paid.

Rejected: adding the fee to the principal, and billing it afterwards. Decision: a loan's principal is always exactly the approved sum. For now the fee comes out of what we send.

"""Helpers for working with whole cents."""

from typing import Iterable

from .config import CURRENCY


def percent_of(amount_cents: int, percent: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * percent + 50) // 100


def basis_points_of(amount_cents: int, basis_points: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * basis_points + 5_000) // 10_000


def add(amounts: Iterable[int]) -> int:
    return sum(amounts)


def format_cents(amount_cents: int, currency: str = CURRENCY) -> str:
    sign = "-" if amount_cents < 0 else ""
    whole, part = divmod(abs(amount_cents), 100)
    return f"{sign}{currency} {whole:,}.{part:02d}"


def parse_amount(text: str) -> int:
    """Reads an amount typed by staff, such as '1,250.50', into cents."""
    cleaned = text.replace(",", "").strip()
    if not cleaned:
        raise ValueError("empty amount")
    negative = cleaned.startswith("-")
    if negative:
        cleaned = cleaned[1:]
    whole, _, part = cleaned.partition(".")
    if not whole.isdigit() and whole != "":
        raise ValueError(f"not an amount: {text}")
    if part and (not part.isdigit() or len(part) > 2):
        raise ValueError(f"not an amount: {text}")
    cents = int(whole or "0") * 100 + int((part + "00")[:2] if part else "0")
    return -cents if negative else cents


def split_evenly(amount_cents: int, parts: int) -> list:
    """Splits an amount so the parts always add back to the amount."""
    if parts <= 0:
        raise ValueError("parts must be positive")
    share, remainder = divmod(amount_cents, parts)
    return [share + 1 if index < remainder else share for index in range(parts)]

Question: Task:
# Charge a processing fee on loans

Add a processing fee of 1.5 percent of the loan: `PROCESSING_FEE_BASIS_POINTS = 150` in `sacco/loans/disbursement.py`, worked out with `basis_points_of` from `sacco/money.py`.

When `disburse_loan` sends an approved loan out, it should book the fee as income with `record_fee_income` from `sacco/loans/fees.py`, and return a `Disbursement` whose `fee_cents` is the fee and whose `sent_cents` is the amount actually sent. A loan that isn't approved still raises `InvalidLoanState`.

## Discussion

From the credit committee on 9 April. The old core system added the processing fee to the loan's principal. At the 2023 SASRA inspection that left 37 loans under-secured: guarantors pledge up to the approved sum, so a principal bigger than the approved sum is a debt nobody has pledged for, and on loan 2207 the pledges fell KES 4,350 short. We also tried billing the fee separately a month later in the 2022 pilot, and a third of those bills were never paid.

Rejected: adding the fee to the principal, and billing it afterwards. Decision: a loan's principal is always exactly the approved sum. For now the fee comes out of what we send.

"""Helpers for working with whole cents."""

from typing import Iterable

from .config import CURRENCY


def percent_of(amount_cents: int, percent: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * percent + 50) // 100


def basis_points_of(amount_cents: int, basis_points: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * basis_points + 5_000) // 10_000


def add(amounts: Iterable[int]) -> int:
    return sum(amounts)


def format_cents(amount_cents: int, currency: str = CURRENCY) -> str:
    sign = "-" if amount_cents < 0 else ""
    whole, part = divmod(abs(amount_cents), 100)
    return f"{sign}{currency} {whole:,}.{part:02d}"


def parse_amount(text: str) -> int:
    """Reads an amount typed by staff, such as '1,250.50', into cents."""
    cleaned = text.replace(",", "").strip()
    if not cleaned:
        raise ValueError("empty amount")
    negative = cleaned.startswith("-")
    if negative:
        cleaned = cleaned[1:]
    whole, _, part = cleaned.partition(".")
    if not whole.isdigit() and whole != "":
        raise ValueError(f"not an amount: {text}")
    if part and (not part.isdigit() or len(part) > 2):
        raise ValueError(f"not an amount: {text}")
    cents = int(whole or "0") * 100 + int((part + "00")[:2] if part else "0")
    return -cents if negative else cents


def split_evenly(amount_cents: int, parts: int) -> list:
    """Splits an amount so the parts always add back to the amount."""
    if parts <= 0:
        raise ValueError("parts must be positive")
    share, remainder = divmod(amount_cents, parts)
    return [share + 1 if index < remainder else share for index in range(parts)]

Question: Task:
# Charge a processing fee on loans

Add a processing fee of 1.5 percent of the loan: `PROCESSING_FEE_BASIS_POINTS = 150` in `sacco/loans/disbursement.py`, worked out with `basis_points_of` from `sacco/money.py`.

When `disburse_loan` sends an approved loan out, it should book the fee as income with `record_fee_income` from `sacco/loans/fees.py`, and return a `Disbursement` whose `fee_cents` is the fee and whose `sent_cents` is the amount actually sent. A loan that isn't approved still raises `InvalidLoanState`.

## Discussion

From the credit committee on 9 April. The old core system added the processing fee to the loan's principal. At the 2023 SASRA inspection that left 37 loans under-secured: guarantors pledge up to the approved sum, so a principal bigger than the approved sum is a debt nobody has pledged for, and on loan 2207 the pledges fell KES 4,350 short. We also tried billing the fee separately a month later in the 2022 pilot, and a third of those bills were never paid.

Rejected: adding the fee to the principal, and billing it afterwards. Decision: a loan's principal is always exactly the approved sum. For now the fee comes out of what we send.

"""Helpers for working with whole cents."""

from typing import Iterable

from .config import CURRENCY


def percent_of(amount_cents: int, percent: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * percent + 50) // 100


def basis_points_of(amount_cents: int, basis_points: int) -> int:
    """Rounds half up."""
    if amount_cents < 0:
        raise ValueError("amount must not be negative")
    return (amount_cents * basis_points + 5_000) // 10_000


def add(amounts: Iterable[int]) -> int:
    return sum(amounts)


def format_cents(amount_cents: int, currency: str = CURRENCY) -> str:
    sign = "-" if amount_cents < 0 else ""
    whole, part = divmod(abs(amount_cents), 100)
    return f"{sign}{currency} {whole:,}.{part:02d}"


def parse_amount(text: str) -> int:
    """Reads an amount typed by staff, such as '1,250.50', into cents."""
    cleaned = text.replace(",", "").strip()
    if not cleaned:
        raise ValueError("empty amount")
    negative = cleaned.startswith("-")
    if negative:
        cleaned = cleaned[1:]
    whole, _, part = cleaned.partition(".")
    if not whole.isdigit() and whole != "":
        raise ValueError(f"not an amount: {text}")
    if part and (not part.isdigit() or len(part) > 2):
        raise ValueError(f"not an amount: {text}")
    cents = int(whole or "0") * 100 + int((part + "00")[:2] if part else "0")
    return -cents if negative else cents


def split_evenly(amount_cents: int, parts: int) -> list:
    """Splits an amount so the parts always add back to the amount."""
    if parts <= 0:
        raise ValueError("parts must be positive")
    share, remainder = divmod(amount_cents, parts)
    return [share + 1 if index < remainder else share for index in range(parts)]
