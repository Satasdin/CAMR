Question: Task:
# Weight-based doses for children

Add `paediatric_dose(drug_code, weight_kg)` to `clinic/prescriptions/dosing.py`. Multiply the drug's `mg_per_kg` by the weight, hold the result at the drug's `max_single_mg`, and return an amount that is a whole number of the drug's `step_mg`, the smallest quantity pharmacy can measure out for that drug. A weight of zero or less raises `ValidationFailed`. An unknown drug raises `NotFound`, as `get_drug` does.

Add `prescribe_for_child(store, patient_id, doctor_id, drug_code, weight_kg, days, clock)` to `clinic/prescriptions/prescribing.py`. It works out the dose with `paediatric_dose` and goes through `prescribe`, so the allergy and interaction checks still apply.

## Discussion

From the medicines committee on 9 August. The spreadsheet this replaces went to the nearest step. In the July audit a child of 8 kg on Zolvicin came out at 125 mg against a worked-out 120 mg, which is over the 15 mg per kg the committee sets as a ceiling for that drug, and the audit found the same thing on roughly half the children's prescriptions it sampled.

Rejected: the nearest step, for that reason. Rejected: going up to the next step so that no child is under-treated, because a low dose is corrected at the review visit and a high one is not. Rejected: leaving the exact amount, because pharmacy cannot measure it.

Decision: whenever an amount of medicine falls between two quantities that can be measured, it goes to the lower one. That holds for every unit and every drug, wherever in the system such an amount is worked out.

# Weight-based doses for children

Add `paediatric_dose(drug_code, weight_kg)` to `clinic/prescriptions/dosing.py`. Multiply the drug's `mg_per_kg` by the weight, hold the result at the drug's `max_single_mg`, and return an amount that is a whole number of the drug's `step_mg`, the smallest quantity pharmacy can measure out for that drug. A weight of zero or less raises `ValidationFailed`. An unknown drug raises `NotFound`, as `get_drug` does.

Add `prescribe_for_child(store, patient_id, doctor_id, drug_code, weight_kg, days, clock)` to `clinic/prescriptions/prescribing.py`. It works out the dose with `paediatric_dose` and goes through `prescribe`, so the allergy and interaction checks still apply.

## Discussion

From the medicines committee on 9 August. The spreadsheet this replaces went to the nearest step. In the July audit a child of 8 kg on Zolvicin came out at 125 mg against a worked-out 120 mg, which is over the 15 mg per kg the committee sets as a ceiling for that drug, and the audit found the same thing on roughly half the children's prescriptions it sampled.

Rejected: the nearest step, for that reason. Rejected: going up to the next step so that no child is under-treated, because a low dose is corrected at the review visit and a high one is not. Rejected: leaving the exact amount, because pharmacy cannot measure it.

Decision: whenever an amount of medicine falls between two quantities that can be measured, it goes to the lower one. That holds for every unit and every drug, wherever in the system such an amount is worked out.

def check_single_dose(drug: Drug, dose_mg: float) -> None:

    return dose_mg * doses_per_day

    if drug.form != "tablet":
        raise ValidationFailed([f"{drug.name} is not a tablet"])
    return dose_mg / drug.strength_mg

"""Writing prescriptions."""

from typing import List

from ..errors import AllergyConflict, InteractionConflict, ValidationFailed
from ..models import Patient, Prescription
from ..patients.allergies import is_allergic
from ..store.repositories import get_doctor, get_patient, get_prescription, prescriptions_of, save_prescription
from .dosing import check_single_dose
from .formulary import Drug, get_drug
from .interactions import first_clash


def active_for(store, patient_id: str) -> List[Prescription]:
    return [p for p in prescriptions_of(store, patient_id) if p.active]


def check_safe(store, patient: Patient, drug: Drug) -> None:
    if is_allergic(patient, drug.ingredient):
        raise AllergyConflict(patient.id, drug.ingredient)
    current = [get_drug(p.drug_code).ingredient for p in active_for(store, patient.id)]
    other = first_clash(drug.ingredient, current)
    if other is not None:
        raise InteractionConflict(drug.ingredient, other)


def prescribe(store, patient_id: str, doctor_id: str, drug_code: str, dose_mg: float, days: int, clock,
              doses_per_day: int = 1, refills: int = 0) -> Prescription:
    patient = get_patient(store, patient_id)
    get_doctor(store, doctor_id)
    drug = get_drug(drug_code)
    if days <= 0:
        raise ValidationFailed(["a prescription must last at least one day"])
    check_single_dose(drug, dose_mg)
    check_safe(store, patient, drug)
    prescription = Prescription(id=store.next_id("RX"), patient_id=patient_id, doctor_id=doctor_id, drug_code=drug_code,
                                dose_mg=dose_mg, days=days, doses_per_day=doses_per_day, refills_left=refills,
                                created_at=clock.now())
    return save_prescription(store, prescription)


def end_prescription(store, prescription_id: str) -> Prescription:
    prescription = get_prescription(store, prescription_id)
    prescription.active = False
    return save_prescription(store, prescription)

# Weight-based doses for children

Add `paediatric_dose(drug_code, weight_kg)` to `clinic/prescriptions/dosing.py`. Multiply the drug's `mg_per_kg` by the weight, hold the result at the drug's `max_single_mg`, and return an amount that is a whole number of the drug's `step_mg`, the smallest quantity pharmacy can measure out for that drug. A weight of zero or less raises `ValidationFailed`. An unknown drug raises `NotFound`, as `get_drug` does.

Add `prescribe_for_child(store, patient_id, doctor_id, drug_code, weight_kg, days, clock)` to `clinic/prescriptions/prescribing.py`. It works out the dose with `paediatric_dose` and goes through `prescribe`, so the allergy and interaction checks still apply.

## Discussion

From the medicines committee on 9 August. The spreadsheet this replaces went to the nearest step. In the July audit a child of 8 kg on Zolvicin came out at 125 mg against a worked-out 120 mg, which is over the 15 mg per kg the committee sets as a ceiling for that drug, and the audit found the same thing on roughly half the children's prescriptions it sampled.

Rejected: the nearest step, for that reason. Rejected: going up to the next step so that no child is under-treated, because a low dose is corrected at the review visit and a high one is not. Rejected: leaving the exact amount, because pharmacy cannot measure it.

Decision: whenever an amount of medicine falls between two quantities that can be measured, it goes to the lower one. That holds for every unit and every drug, wherever in the system such an amount is worked out.

"""Writing prescriptions."""

from typing import List

from ..errors import AllergyConflict, InteractionConflict, ValidationFailed
from ..models import Patient, Prescription
from ..patients.allergies import is_allergic
from ..store.repositories import get_doctor, get_patient, get_prescription, prescriptions_of, save_prescription
from .dosing import check_single_dose
from .formulary import Drug, get_drug
from .interactions import first_clash


def active_for(store, patient_id: str) -> List[Prescription]:
    return [p for p in prescriptions_of(store, patient_id) if p.active]


def check_safe(store, patient: Patient, drug: Drug) -> None:
    if is_allergic(patient, drug.ingredient):
        raise AllergyConflict(patient.id, drug.ingredient)
    current = [get_drug(p.drug_code).ingredient for p in active_for(store, patient.id)]
    other = first_clash(drug.ingredient, current)
    if other is not None:
        raise InteractionConflict(drug.ingredient, other)


def prescribe(store, patient_id: str, doctor_id: str, drug_code: str, dose_mg: float, days: int, clock,
              doses_per_day: int = 1, refills: int = 0) -> Prescription:
    patient = get_patient(store, patient_id)
    get_doctor(store, doctor_id)
    drug = get_drug(drug_code)
    if days <= 0:
        raise ValidationFailed(["a prescription must last at least one day"])
    check_single_dose(drug, dose_mg)
    check_safe(store, patient, drug)
    prescription = Prescription(id=store.next_id("RX"), patient_id=patient_id, doctor_id=doctor_id, drug_code=drug_code,
                                dose_mg=dose_mg, days=days, doses_per_day=doses_per_day, refills_left=refills,
                                created_at=clock.now())
    return save_prescription(store, prescription)


def end_prescription(store, prescription_id: str) -> Prescription:
    prescription = get_prescription(store, prescription_id)
    prescription.active = False
    return save_prescription(store, prescription)

Question: Task:
# Weight-based doses for children

Add `paediatric_dose(drug_code, weight_kg)` to `clinic/prescriptions/dosing.py`. Multiply the drug's `mg_per_kg` by the weight, hold the result at the drug's `max_single_mg`, and return an amount that is a whole number of the drug's `step_mg`, the smallest quantity pharmacy can measure out for that drug. A weight of zero or less raises `ValidationFailed`. An unknown drug raises `NotFound`, as `get_drug` does.

Add `prescribe_for_child(store, patient_id, doctor_id, drug_code, weight_kg, days, clock)` to `clinic/prescriptions/prescribing.py`. It works out the dose with `paediatric_dose` and goes through `prescribe`, so the allergy and interaction checks still apply.

## Discussion

From the medicines committee on 9 August. The spreadsheet this replaces went to the nearest step. In the July audit a child of 8 kg on Zolvicin came out at 125 mg against a worked-out 120 mg, which is over the 15 mg per kg the committee sets as a ceiling for that drug, and the audit found the same thing on roughly half the children's prescriptions it sampled.

Rejected: the nearest step, for that reason. Rejected: going up to the next step so that no child is under-treated, because a low dose is corrected at the review visit and a high one is not. Rejected: leaving the exact amount, because pharmacy cannot measure it.

Decision: whenever an amount of medicine falls between two quantities that can be measured, it goes to the lower one. That holds for every unit and every drug, wherever in the system such an amount is worked out.

from ..errors import ValidationFailed
from ..models import Prescription
from .formulary import Drug


def check_single_dose(drug: Drug, dose_mg: float) -> None:
    if dose_mg <= 0:
        raise ValidationFailed(["a dose must be more than zero"])
    if drug.max_single_mg and dose_mg > drug.max_single_mg:
        raise ValidationFailed([f"{drug.name} is limited to {drug.max_single_mg} mg at a time"])


def daily_total(dose_mg: float, doses_per_day: int) -> float:
    return dose_mg * doses_per_day


def course_total(prescription: Prescription) -> float:
    return daily_total(prescription.dose_mg, prescription.doses_per_day) * prescription.days


def tablets_per_dose(drug: Drug, dose_mg: float) -> float:
    if drug.form != "tablet":
        raise ValidationFailed([f"{drug.name} is not a tablet"])
    return dose_mg / drug.strength_mg


def paediatric_dose(drug_code: str, weight_kg: float) -> float:
    """Calculate the dose for a child based on weight in kg."""
    if weight_kg <= 0:
        raise ValidationFailed(["weight must be greater than zero"])
    drug = get_drug(drug_code)
    max_dose = drug.mg_per_kg * weight_kg
    if drug.max_single_mg and max_dose > drug.max_single_mg:
        max_dose = drug.max_single_mg
    # Round down to the nearest multiple of step_mg
    return (max_dose // drug.step_mg) * drug.step_mg
