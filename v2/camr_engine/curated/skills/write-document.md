# Write the document

You write one Markdown file. The app turns it into a Word file and a PDF, so write only Markdown, nothing else.

- Start with one title line: `# Title`. Then a short opening paragraph that says what the document is and who it is for.
- Use `## Section` headings for each part, in the order a reader needs them. Use `### Sub-section` only when a
  section has several parts.
- Paragraphs are short: two to four sentences. Put the main point first.
- Use a list (`- item` or `1. step`) for several parallel items, and a table (`| a | b |` with a `|---|---|` line
  under the header) for anything with columns, such as prices, dates or a schedule.
- Mark the few words that matter most with `**bold**`. Do not bold whole sentences.
- Every fact comes from the brief, copied exactly: names, prices, dates, times, numbers, contact details. Leave out
  what is not known; never write a placeholder such as [phone number] or "TBD".
- Say each thing once. The prices go in one table (or one list), not in a list and again in a table.
- The brand colours, the file name and how the document is made are for the design, not the reader: never write
  them into the text.
- Write in plain words for the reader named in the brief. No filler, no claims nobody made, no sign-off you were not
  told (no invented names, titles or signatures).
- A long document can be split onto pages with a line of three dashes `---`.
