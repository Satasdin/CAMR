# Review and fix

- Open the page with open_page and read every problem it reports.
- Fix one problem at a time with edit_file, copying the old text exactly from the page as it is now. When a fix needs most of a file changed, write the whole file again, keeping every section, button, script and fact that already works.
- Facts the report says are missing go back onto the page exactly as told. Facts it says are made up come off, or you ask the person with ask_user.
- After fixing, open the page again. Stop when the report has no problems, and say plainly what you checked and what is still wrong.
