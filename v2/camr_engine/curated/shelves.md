name: shelves
label: Making shelves
about: How to make a good shelf of your own: what to put on it, how to word it, and how to keep it useful.
---
RULE A shelf holds one subject a person returns to: a project, a client, a style of work. Name it for that.
RULE Write each note as one fact or one rule, in one or two sentences. A long note is several notes stuck together.
RULE Start a rule with what to do, not why: "Use KES for every price." The reason can follow.
RULE Put the exact values on the shelf: names, prices, times, colours, numbers. These are what a model gets wrong when it guesses.
RULE Add a correction when the model gets something wrong: the wrong version and the right one, side by side.
RULE Keep facts that change apart from facts that do not. Opening hours change; a shop's name rarely does.
RULE When a fact changes, change the note, do not add a second one. Two versions of a fact is worse than none.
RULE A shelf that is called only when needed keeps every other answer short. Mark general knowledge as called.
RULE Keep a shelf under a few hundred notes. Past that, split it by subject.
RULE Do not put secrets on a shelf: passwords, keys, private numbers.
RULE Write notes in the words a person would use to ask about them, so the right note is found.
RULE A shelf of rules for a kind of work (design, writing) should be checked against real results now and then: keep what helps, drop what does not.
RULE Remove a shelf you no longer use. Removed shelves can be brought back; clutter slows every look.
RULE One subject per note. "Open 10 to 7; phone 0722..." is two notes.
RULE Say where a fact came from when it matters: told by the owner, read from the menu.
RULE Read a shelf back once after making it. If a note would confuse a new person, it will confuse the model.
CORRECTION Wrong: a shelf called "Stuff". Right: a shelf called "Riverside Plumbing".
CORRECTION Wrong: "Prices are around 300-2000". Right: one note per price, exact.
CORRECTION Wrong: two notes saying the shop closes at 6 and at 7. Right: one note, the current time.
CORRECTION Wrong: a note that is a whole page pasted in. Right: the page split into one fact per note.
CORRECTION Wrong: "be nice in emails". Right: "Start emails with the person's first name and end with Thanks, Wanjiru".
CORRECTION Wrong: keeping a password on a shelf "for convenience". Right: no secrets on any shelf.
CORRECTION Wrong: a correction with only the right version. Right: the wrong version and the right one, so the mistake is recognised.
CORRECTION Wrong: one huge shelf for everything. Right: a shelf per subject, called when its subject comes up.
